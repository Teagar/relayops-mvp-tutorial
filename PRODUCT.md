# RelayOps MVP

Dashboard operacional local-first para triagem de tickets de suporte.

## Escopo

- CRUD completo de tickets.
- Busca por texto e filtros por prioridade/status.
- Fluxo `inbox → progress → resolved`.
- Métricas derivadas do estado real.
- Persistência em `localStorage`.
- Exportação e importação JSON validada.
- Reset seguro para dados de demonstração.
- Layout responsivo e acessível derivado de `design/reference.svg`.

## Fora do MVP

Autenticação, backend, colaboração em tempo real e integrações externas.
